# The Ghost Writer

A Pen created on CodePen.

Original URL: [https://codepen.io/marco-ponds/pen/gawVZY](https://codepen.io/marco-ponds/pen/gawVZY).

Type as fast as you can to kill the ghosts! You must use only keys from "a" to "z" to shoot with the cannon, otherwise more ghosts will appear. Beware! Not every key is allowed, and they randomly change their behaviour.. Let's see how far you can get! (this 2D game has been developed with no external libraries, except for Sweetalert).
