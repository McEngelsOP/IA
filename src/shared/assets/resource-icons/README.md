# Resource icons

Public site favicons retrieved on 2026-10-13 via Google's favicon endpoint (`https://www.google.com/s2/favicons?domain=HOST&sz=64`) and decoded/re-encoded as PNG. Original provider branding is preserved. The filename identifies the provider hostname; auth.tidbcloud.com uses tidbcloud.com. Kept with the app to avoid third-party hotlink restrictions. New domains continue to use runtime favicon discovery.
