# Uso del código de Lyra

El código original de Lyra no se ofrece bajo una licencia de código abierto.
Su disponibilidad en GitHub no constituye una autorización general para
redistribuirlo, incorporarlo a otro producto o comercializarlo.

Los componentes de terceros conservan sus licencias y avisos originales.

Para probar Lyra, comparte la dirección de la aplicación publicada. El acceso
al repositorio debe limitarse a las personas que colaboran en su desarrollo.
