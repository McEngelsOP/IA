# Piloto ESAN y expansión

Las 18 carreras del catálogo están disponibles. La validación de uso puede comenzar con grupos pequeños sin cerrar las demás opciones de registro. Las prioridades son persistencia, reglas curriculares, configuración del semestre y retorno semanal. Focus, grupos, recursos y Arcade siguen como complementos.

## Indicadores propuestos

| Medida | Definición |
| --- | --- |
| Configuración | Quienes terminan / quienes empiezan. |
| Primer valor | Tiempo hasta preparar avance y matrícula o confirmar un horario. |
| Retención | Usuarios de la cohorte que realizan una acción útil en semana 4. |
| Error curricular | Reportes confirmados sobre créditos, requisitos o versión. |
| Soporte | Minutos de atención por estudiante activo. |
| Continuidad | Estudiantes que preparan el siguiente ciclo / cohorte anterior. |

Es un protocolo pendiente de validación con estudiantes, no resultados observados. Todavía no hay un panel central de telemetría que mida estos indicadores automáticamente. Su recolección debe diseñarse con eventos mínimos y finalidades claras.

Primero comprobar confiabilidad y uso sostenido dentro de ESAN. Después verificar que una institución adicional puede incorporarse por configuración y datos. Registros aislados no justifican expansión.

Cobros, contratos institucionales, integraciones LMS y aplicación nativa requieren validación y desarrollo propios; no se activan en esta reorganización.
